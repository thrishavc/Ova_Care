# Ova_Care
A multilingual, safety-first menstrual and hormonal health triage companion. Ova_care listens to symptoms via voice/text in English, Hindi, and regional mixes, screens red flags, offers grounded educational insights, and generates one-page doctor visit briefs—with zero medical diagnosis or prescribing.

> Ova_Care gives general information, not a diagnosis. Please see a doctor for advice about your health.

## Run locally

1. Install Node.js 20+.
2. `npm install`
3. Copy `.env.example` to `.env.local` and fill in `GEMINI_API_KEY` and `MONGODB_URI` (ask Member 1 privately — never commit secrets).
4. `npm run dev` and open http://localhost:3000

The team plan and checklists are in [`docs/`](docs/).
